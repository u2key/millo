# Millo — ボクセル・アクション

ブラウザで遊べる、ブロックでできた世界の 3D アクションゲームです。
プレイヤーは **ワールドを遊ぶ** ことも **ワールドを作る** こともでき、自分や敵のキャラクターをモデリングすることもできます。
クリアタイムはワールドごとのランキングで競えます。

- バックエンド: Node.js（Express）+ SQLite（sqlite3）+ WebSocket（ws）
- フロントエンド: three.js（ビルド不要の ES Modules）
- ポート: `25830`

## 特長

- **3D アクション** — 走る、ジャンプ（長押しで高く）、ダッシュ、敵の踏みつけ。中間旗、ジャンプ台、溶岩、氷の床
- **キャラクター** — デフォルトでプレイヤー 3 種・敵 10 種（すべて本プロジェクトのオリジナルデザイン）
- **モデリング** — 24×32×24 のボクセルエディタ（置く／消す／ブラシで塗る／塗りつぶし／スポイト／左右対称）
  - 画像ファイル（正面図として押し出し）、STL ファイル（ボクセル化）からも作成可能
  - **関節の自動認識** — 形から頭・腕・脚を見つけ、歩く・跳ぶアニメーションを自動で付与
- **ワールドエディタ** — ブロック配置／範囲塗りつぶし、スタート・ゴール・クリスタル・中間旗・敵・ボスの配置、元に戻す／やり直し、テストプレイ
- **クリスタルでワールド開放** — 開放に必要なクリスタル数をワールドごとに設定。クリスタルは消費されず、所持数は減りません
- **ランキング** — クリアタイム順。ワールドアイコンのマウスホバーで TOP5、クリックで全順位
- **オンラインモード** — 同じワールドを遊んでいる他のプレイヤーがリアルタイムで見える（名前表示・チャット・クリア速報）
- **入力** — キーボード＋マウス、ゲームパッド（Gamepad API の標準マッピング）

## はじめかた

Node.js 18 以上が必要です。

```bash
git clone <このリポジトリ>
cd millo
npm install
npm start
```

ブラウザで <http://localhost:25830> を開き、名前とパスワードを登録すると遊べます。
初回起動時に初期ワールドが 3 つ自動で作られます。

| 環境変数 | 既定値 | 内容 |
|---|---|---|
| `PORT` | `25830` | 待ち受けポート |
| `DB_FILE` | `data/millo.sqlite3` | SQLite データベースのパス |

データをすべて消して最初からやり直すには、サーバーを止めて `data/` を削除します。

## 遊び方

1. ワールド一覧からワールドを選ぶ（ホバーでランキング TOP5、クリックで詳細と全順位）
2. 「ソロでプレイ」か「オンラインでプレイ」を選ぶ
3. アバターを選ぶ（ここで新しく作ったり、既存モデルを元に編集したりもできます）
4. ゴールゲートにたどり着けばクリア。タイムがランキングに登録されます

ルール:

- 敵は **上から踏みつけて** 倒します。横から当たるとダメージ（ハート 3 つ）
- トゲボールは踏めません。ボスは何度も踏む必要があります
- 溶岩に触れるとダメージ。ピンクのジャンプ台で大ジャンプ
- 落下や体力ゼロでミスになり、最後に触れた中間旗（なければスタート）から再開。タイマーは止まりません
- 黄色のクリスタルを持ったままクリアすると、所持クリスタルとして記録されます。取得済みのクリスタルは青く表示されます
- 鍵のついたワールドは、所持クリスタルの合計が条件の数に達すると遊べるようになります

### 操作

| | キーボード＋マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印キー | 左スティック / 十字キー |
| ジャンプ | Space（長押しで高く） | A / B |
| ダッシュ | Shift | X / RB / RT |
| カメラ | マウス（画面クリックでポインタロック）/ Q・E | 右スティック |
| ズーム | ホイール | LB / LT |
| ポーズ | Esc / P | Start |
| 最初から | R | Back / Select |
| チャット（オンライン時） | T / Enter | — |

### オンラインモード

- 同じワールドをオンラインで遊んでいる人が、名前つきで表示されます
- `T` か `Enter` でチャット。誰かがクリアすると、タイムと順位が全員に流れます
- 他のプレイヤーの頭に乗ると跳ねます
- 敵・クリスタル・タイマーは各プレイヤーで独立しています（タイムアタックを公平にするため）。記録はソロと同じランキングに入ります

## ワールドを作る

ワールド一覧の「＋ ワールドを作る」で新しく作るか、既存ワールドの「複製して編集」を使います。

- **ブロック**: 置く（B）／消す（X）／塗り替え（P）／範囲（G：2 点をクリックして直方体を埋める。✕ を選ぶと削除）
- **配置物**: スタート（1 つ）、ゴール（**1 つ以上必須**）、クリスタル（数の上限なし）、中間旗、敵。`R` で向きを回転
- **ボス**: 敵を置くときに「ボスにする」をチェックすると、大きく体力の多い敵になります（配置は任意）
- **⚙ 設定**:
  - 開放に必要なクリスタル数
  - 空（昼・夕焼け・夜）
  - 「ボスを全員倒すまでゴールを閉じる」
  - ワールドのサイズ
  - 敵の種類ごとの見た目（自作モデルやほかの人のモデルに差し替え可能）
- **▶ テストプレイ** で記録を残さずに試せます。保存してもランキングはリセットされません

カメラ操作: 右ドラッグで回転、中ドラッグ／Shift+右ドラッグで移動、ホイールでズーム、WASD・QE で視点移動、Alt+クリックでブロックを拾う、Ctrl+Z／Ctrl+Y／Ctrl+S。

## キャラクターを作る

ワールド一覧の「🧍 モデル工房」か、プレイ前のアバター選択画面から開きます。

- **白紙から** / **既存モデルを元に** / **画像から** / **STL から** 作成できます
  - 画像: 透過 PNG 推奨。透過がない場合は左上の色を背景とみなして取り除き、指定した奥行きで押し出します
  - STL: バイナリ・ASCII の両方に対応。表面をボクセル化して内部を埋めます。色はあとから「塗る」ツールで付けられます
- ツール: 置く（B）／消す（X）／塗る（P、ブラシサイズ 1〜4）／塗りつぶし（F）／スポイト（I）、左右対称（M）
- 正面は青い矢印の向き（+Z）です
- 「関節」表示で自動認識した部位と関節の位置（赤い点）を、「動き」表示で歩行アニメーションを確認できます

### 関節の自動認識のしくみ

1. 足元の断面が 2 つ以上に分かれていれば、その上端を股関節とする。脚がくっついている場合は、腕の始まりでシルエットが急に広がる高さを股関節とする
2. 脚の左右の外側に張り出した、箱に近い形の塊を腕とする。肩の上が細くなっていることも条件にする
3. 肩より上を頭、残りを胴体とする
4. 当てはまらない形（スライムなど）は一体型として、伸び縮みする動きを付ける

## ディレクトリ構成

```
server/
  index.js      Express サーバー・REST API
  realtime.js   オンラインモード（WebSocket /ws）
  db.js         SQLite スキーマ
  seed.js       初期ワールドの生成
shared/
  world.js      クライアントとサーバーで共有する定義（ブロック・敵種別・検証・RLE 圧縮）
public/
  index.html, css/style.css
  js/main.js         画面遷移・ワールド一覧・ランキング・アバター選択
  js/game.js         ゲームプレイ（プレイヤー・敵 AI・HUD）
  js/net.js          オンライン接続とほかのプレイヤーの表示
  js/worldEditor.js  ワールドエディタ
  js/modelEditor.js  モデルエディタ
  js/rig.js          関節の自動認識とアニメーション
  js/importers.js    画像・STL → ボクセル変換
  js/voxel.js        メッシュ生成・レイキャスト・当たり判定
  js/models.js       デフォルトキャラクター
  js/input.js        キーボード・マウス・ゲームパッド入力
  js/sfx.js          効果音（Web Audio で合成）
```

## API 概要

| メソッド | パス | 内容 |
|---|---|---|
| POST | `/api/register`, `/api/login`, `/api/logout` | アカウント（Bearer トークン） |
| GET | `/api/me` | 自分の情報と所持クリスタル数 |
| GET | `/api/worlds` | ワールド一覧（TOP5・オンライン人数つき） |
| GET / POST / PUT / DELETE | `/api/worlds/:id` | ワールドの取得・作成・更新・削除 |
| GET | `/api/worlds/:id/ranking` | ランキング（上位 100） |
| POST | `/api/worlds/:id/clear` | クリア記録とクリスタル取得の登録 |
| GET / POST / PUT / DELETE | `/api/models/:id` | モデルの取得・作成・更新・削除 |
| WS | `/ws?token=…` | オンラインモード（join / state / chat / clear） |

## 注意事項

- クリアタイムはクライアントが申告する値で、サーバー側では簡単な範囲チェックしかしていません。公開運用で不正対策が必要なら、リプレイ検証などを追加してください
- 自分が作ったワールドで集めたクリスタルも所持数に数えられます
- オンラインモードはサーバーが位置とチャットを中継するだけで、敵の状態は共有しません
